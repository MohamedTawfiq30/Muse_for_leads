# Solvrex Lead Generation Agent

An AI-powered lead generation workflow built using **Muse** to generate business leads based on a target industry, city, and required lead count. The agent exports the collected data into an Excel spreadsheet, which can then be enhanced with visualizations using ChatGPT.

## Overview

This repository contains the setup package, agent instructions, and visualization prompt required to run the Solvrex Lead Generation Agent.

**Workflow:**

1. Set up the agent in Muse.
2. Enter the target business category, city, and number of leads.
3. Generate an Excel file containing the collected leads.
4. Use ChatGPT to transform the Excel file into a professionally formatted, visualization-ready spreadsheet while preserving the full dataset.

## Repository Files

| File | Description |
|---|---|
| `Solvrex setup package.zip` | Setup package required to configure the agent in Muse. |
| `AgentSetup_Prompt.txt` | Instructions for creating and configuring the lead generation agent. |
| `LeadsVisualizationPrompt.txt` | Instructions for improving the Excel sheet with formatting, dashboards, and visualizations. |

## Prerequisites

- Muse desktop application.
- VPN access if required to access Muse from India.
- ChatGPT for Excel visualization.
- The setup files provided in this repository.

## Step 1: Set Up the Agent in Muse

1. Download and install Muse.
2. If you are in India and Muse is unavailable in your region, use a VPN where permitted by the service's terms.
3. Open Muse and start a new chat.
4. Upload the following files:
   - `Solvrex setup package.zip`
   - `AgentSetup_Prompt.txt`
5. Follow the prompt instructions to create and configure the lead generation agent.
6. Verify that the agent workflow has been created successfully before generating leads.

## Step 2: Generate Business Leads

Open the configured agent and enter your target business category, city, and required number of leads.

**Example input:**

```text
Business: Gym
City: Delhi
Number of Leads: 250
```

You can change the business category, city, and lead count based on your requirements.

**Expected output:** An Excel spreadsheet containing the generated business lead data.

Once the file is generated, download it and verify that the data is available before proceeding.

## Step 3: Visualize the Excel Sheet Using ChatGPT

The generated Excel file may need better formatting, organization, and visual analysis. Use ChatGPT to enhance its presentation without losing the original lead data.

1. Open ChatGPT.
2. Upload the Excel file generated by Muse.
3. Upload or paste the contents of `LeadsVisualizationPrompt.txt`.
4. Ask ChatGPT to follow the prompt and create a professionally formatted, visualization-ready Excel workbook.
5. Download the resulting Excel file and review the output.

### Expected Visualization Improvements

Depending on the available data and the instructions in the visualization prompt, the enhanced workbook may include:

- A professional dashboard with key lead metrics.
- Summary charts and visual representations of the data.
- Properly formatted column headers and tables.
- Filters and sorting for easier lead management.
- Organized worksheets and consistent formatting.
- Complete lead data preserved in the final workbook.

**Important:** Verify that the final workbook contains all the original lead records. Dashboard summaries and charts should complement the full dataset, not replace it.

## Example Use Case

Generate 250 gym leads in Delhi using Muse, export the results to Excel, and then use ChatGPT to produce a dashboard with useful summaries and visualizations alongside the complete lead list.

The same workflow can be reused for other industries and cities by changing the input parameters.

## Notes

- Lead quantity and completeness depend on the agent workflow and available data sources.
- Generated business information should be verified before sales outreach.
- Do not assume that every generated lead has verified contact details.
- Keep the original Excel file as a backup before applying transformations.
- Ensure that all required columns and records are retained in the final workbook.
